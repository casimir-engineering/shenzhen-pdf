- Every Markdown page now carries "Page 2 of 10" right-aligned in its footer — on screen, in Print, Save as PDF and Copy Page alike. It is drawn with the page, not typeset, so it never turns up as a search hit.
- A link in a Markdown table cell looked like a link and did nothing when clicked, and the pointer never changed over it. Cell links now open like any other, with the hand cursor over them.
